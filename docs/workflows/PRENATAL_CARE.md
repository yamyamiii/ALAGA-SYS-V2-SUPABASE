# Prenatal Care Workflow

1. A midwife selects an active female resident and creates one active pregnancy.
2. A midwife or assigned nurse records prenatal events with same-resident
   appointment/encounter links.
3. Clinical notes remain separate from appointment operational notes.
4. Request keys make retries safe; versions reject stale edits.
5. Delivery status requires a delivery outcome.

Dashboard data is aggregate-only and residents see only their own episode.
